# Dracula Neon · Typography Light 2

**발행: 2026-11-23**
**요청:** “좌측 프로젝트명·채팅 제목부터 우측 본문까지 지금의 70% 수준의 볼드만 유지”

## 수정 기준

기존 v8.3.1의 '400을 초과하는 분량의 30% 감소' 대신, **이전 굵기의 70% 수준**을 직접 목표로 설정했습니다.

- 명시된 굵기: `max(320, round(0.70 × 기존 가중치 / 10) × 10)`
- 프로젝트명 이전 610 → 430
- 선택 채팅명 이전 600 → 420
- 강조 문구 이전 610 → 430
- RUN/DONE 상태 배지 이전 750 → 530
- 410 이하의 본문/라벨은 320의 최소값을 유지
- ChatGPT 기본 CSS의 bold/semibold 클래스도 다시 정규화
- Life Clock과 Status는 Shadow DOM·스크립트 내부 스타일을 직접 수정

## 배포 버전

- ChatGPT CSS **8.3.2**
- Clock JS **3.10.2**
- Status JS **6.8.2**
- Mapper JS **1.3.6** 유지
- Google Calendar 변경 없음

## 검증

기존 디자인·색상·그림자·레이아웃·기능 변경 없이 폰트 굵기 규칙만 수정했습니다. JS 구문 검증과 배포 원본 일치 및 SHA256는 검증 대상으로 관리하며 **실제 로그인 Chrome 화면 검증은 별도**입니다.

줄바꿈·보조 라벨 가독성과 네이티브 UI 클래스 우선순위는 사용자 화면에서 재확인합니다.
