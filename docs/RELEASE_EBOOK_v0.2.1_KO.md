# E-book Editorial Notebook v0.2.1 — 변경 내역

**검수일:** 2026-11-24
**범위:** E-book 테마 전용 CSS/JS. Dracula·Flat Neon·핵심 기능 유지.

| 영역 | 기존 v0.2.0 | 수정 v0.2.1 |
|---|---|---|
| 일반 본문 | 14px | 2pt 감소 요청에 대해 CSS 계산 적용, 하한 12px |
| 프로젝트·채팅 목록 | 14px | 유지 |
| 프롬프트 타이핑 | 14px | 유지 |
| 첨부·입력 구획 | 별도 선 없음 | 이미지/첨부 미리보기 감지 시 연회색 수평선 |
| 프롬프트 외곽 | 베이지 테두리·포커스 | 1px 차콜 외곽, 그림자·글로우 제거 |
| 내 메시지 | 밝은 카드 배경, 앰버 테두리 | 투명 배경, 2px 차콜 테두리 |
| 선택 모델/강도 | 옅은 보조 텍스트 | 표시 버튼 감지 시 굵은 차콜 + 화살표 |

**주의:** `14px - 2pt`의 단순 환산값은 약 11.33px이다. 이번엔 너무 작은 글자를 피하기 위해 `max(12px, calc(var(--eb-ui-size) - 2pt))`로 제한했다. 추후 사용자 화면 검수에 따라 11.5~13px 범위에서 재조정할 수 있다.

**검수 상태:** JS 구문, CSS 괄호 및 GitHub 원본/배포 파일 일치 확인. 사용자 로그인 Chrome의 실제 selector 매칭·응답 텍스트 크기·첨부 업로드 구획/모델 선택 강조는 별도 시각 검증 필요. 기존 ChatGPT UI는 업데이트될 수 있다.
