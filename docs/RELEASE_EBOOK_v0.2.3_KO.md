# E-book Editorial Notebook v0.2.3 · 글꼴·입력창 정밀 수정

**2026-11-24**

요구: 여러 차례 본문 크기를 줄였으나 사용자 의도는 사실 **좌측 프로젝트명·채팅명과 우측 본문 및 작성 중인 프롬프트의 크기를 같은 수준으로 맞추는 것**이었다. 기존 0.2.2에서 서로 다른 font-size 선언을 합치지 않고 누적해 생긴 차이를 제거하기 위해 공통 CSS 변수를 사용한다.

## 변경 전후

| 요소 | v0.2.2 | v0.2.3 |
|---|---|---|
| 프로젝트·채팅명 | 14px 계열 | 공통 기준 14px |
| Assistant 본문 | 11.2px | 공통 기준 14px |
| 전송된 User 메시지 | 10.8px | 공통 기준 14px |
| 작성 중인 텍스트 | 14px 계열 | 공통 기준 14px |
| 영문/숫자 폰트 | 혼합: 주로 Pretendard | IBM Plex Mono 우선 |
| 한글 폰트 | Pretendard | Pretendard Variable 폴백 |
| 업로드 분리선 색상 | 연회색 | 차콜 액센트 `#1F1E1A` |
| 프롬프트 외곽 | 차콜 1px | 사용자 메시지와 동일한 2.5px |

### 주의사항
본문 텍스트는 다시 크게 조정된 것이 아니라, 사용자가 요청한 **시각적 크기 일치**를 코드상 같은 단위로 만든 것임. 다양한 DOM 구성이 있을 수 있어 실제 Computed Style을 검수하는 진단을 E-book JS에 추가했다. 문자열 내용·원본 데이터는 바꾸지 않는다.

Dracula, Flat Neon, Life Clock, Status, Mapper, 개인 프로필은 전혀 수정하지 않는다. 실제 로그인 Chrome에서 모든 텍스트 노드의 font-size·font-family가 기대와 일치하는지는 별도 검증한다.
