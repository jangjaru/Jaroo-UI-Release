# E-book v0.2.5 — Sidebar Type Scale

사용자 지시: 우측 본문은 건드리지 말고 좌측 영역 글자 크기를 기존보다 2pt 정도 크게 시험.

| 영역 | 변경 |
|---|---|
| 좌측 프로젝트명 | 14px → 16.67px (+2pt) |
| 좌측 채팅명 | 14px → 16.67px (+2pt) |
| 좌측 탐색 레이블 | 별도 최종 CSS 선택자로 증가 |
| 작은 상태·카운터 글씨 | 11px 기준 +2pt (13.67px) |
| 우측 본문·프롬프트 | 변경 없음 |
| 클래식 페이퍼 배경·폰트·색 | 변경 없음 |
| E-book JS · 핵심 JS · 다른 테마 | 변경 없음 |

시각 검수 전. 동적 DOM 구조와 화면 폭에 따라 말줄임 처리·실제 크기는 달라질 수 있음.
