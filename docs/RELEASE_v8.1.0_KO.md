# ChatGPT UI · Neo-Brutalist 8.1.0

- 본문·채팅명·프로젝트명에 같은 Pretendard 크기를 적용했습니다. 기본 설정 기준 15px이며, 본문과 채팅명은 400, 프로젝트명은 600입니다.
